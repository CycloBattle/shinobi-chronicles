# Shinobi Chronicles – JDR textuel Naruto (v2)

Fichiers à déposer à la RACINE du dépôt GitHub :
index.html, style.css, script.js, data/ (canon.json + characters.json), assets/ (naruto-map.jpg), README.md

Si tu avais déjà déposé la v1, supprime les anciens fichiers devenus inutiles : ai.js et data/player.json.

Premier lancement : crée ton personnage, puis colle ta clé Gemini (https://aistudio.google.com → Get API key).
Test local : `python -m http.server` puis http://localhost:8000
Le dossier optionnel/ contient un proxy Cloudflare (utile seulement si tu partages le lien).
