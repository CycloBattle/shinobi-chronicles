# Shinobi Chronicles – JDR solo Naruto

1. Décompresse ce ZIP.
2. Sur GitHub : New repository (Public) → Add file → Upload files → glisse le CONTENU du dossier
   (index.html, style.css, script.js, ai.js, data/, assets/).
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. Ouvre https://TON-PSEUDO.github.io/NOM-DU-DEPOT/ puis clique sur « ⚙️ Activer l'IA » et colle ta clé Gemini
   (https://aistudio.google.com → Get API key).

Test local : `python -m http.server` puis http://localhost:8000
Le dossier `optionnel/` contient le proxy Cloudflare (inutile si tu es seul à jouer).
